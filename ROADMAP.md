# DarkGram — план работ

Форк Swiftgram, который сам является форком Telegram-iOS. Здесь только то, что
добавлено или изменено в DarkGram, и то, что предстоит сделать.

## Готово

| Фича | Где реализовано |
|---|---|
| Ребрендинг DarkGram | строки локализаций, plist, все зашитые литералы |
| Своя иконка приложения | `Telegram/Telegram-iOS/DarkGram.icon` (Icon Composer) |
| 16 альтернативных иконок | `Telegram/Telegram-iOS/DG*.alticon` |
| Тёмная тема по умолчанию | `PresentationThemeSettings.defaultSettings` |
| Разблокированный Pro | `SGStatus.default`, отключена серверная сверка |
| Вырезана реклама в каналах | `ChatHistoryListNode` |
| Очистка utm и click-меток | `OpenUrl.canonicalExternalUrl` |
| Ghost Mode | 4 сетевых шва в `TelegramCore` |
| Хранение удалённых сообщений | `DarkGramDeletedMessageAttribute` |
| История правок сообщений | `DarkGramEditHistoryAttribute` |
| Маркер удалённых в пузыре | `stringForMessageTimestampStatus` |
| Просмотр истории правок | контекстное меню сообщения |
| Обход защиты копирования | `Message.isCopyProtected` |
| Подтверждение отправки в группы | `ChatControllerImpl.sendMessages` |
| Уведомления по ключевым словам | труба `darkGramKeywordMessages` |
| Шаблоны быстрых ответов | `SGInputToolbar` + `insertText` |
| Локальные псевдонимы контактов | `PeerTitle.swift`, обе точки отображения |
| Экспорт чата в HTML | `DarkGramChatExport.swift` |
| Один раздел настроек с категориями | `SGSettingsController` |

Автоперевод всего чата работал в Swiftgram изначально — гейт снят припиской
`|| true`, писать ничего не потребовалось.

## Ветки

Идут цепочкой, каждая содержит всё из предыдущей:

```
master → batch2 → batch3 → batch4
```

Сборка ветки запускается вручную через `gh workflow run build.yml --ref <ветка>`.
Пуш в `master` собирает автоматически. Сборки разных веток друг друга не
отменяют — группа конкурентности включает имя ветки.
